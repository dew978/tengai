# 사신비행 四神飛行 — 초등 5·6학년 복습 슈팅

달을 삼키려는 흑철 요괴군에 맞서는 모바일 횡스크롤 슈팅 게임이자, 초등 5·6학년 복습 게임입니다.
90년대 오락실 슈팅(텐가이)을 참고했고, 조선 판타지에 증기기관 분위기를 섞었습니다.
캐릭터·적·보스·배경·발사체는 고해상도 일러스트(`art/`)를 쓰고, 수호자·적·보스·신수는 날개·옷자락·불꽃이 움직이는 6장짜리 움직임으로 그립니다. 화면은 기기 해상도에 맞춰 선명하게 그리되, 태블릿은 처음부터 가벼운 해상도로 시작하고 어떤 기기든 프레임이 계속 밀리면 해상도와 작은 효과를 자동으로 낮춥니다(주소 뒤에 `?fps`를 붙이면 화면 아래에 fps가 보입니다). 배경음(타이틀·스테이지·보스)과 효과음은 로컬 생성 모델(Stable Audio 3 Medium)로 만든 소리를 `audio/`에 담아 씁니다.

## 실행

- [브라우저에서 플레이](https://dew978.github.io/tengai/)
- 로컬에서 실행할 때는 저장소를 내려받고 `index.html`을 브라우저에서 엽니다.
- GitHub Pages(Settings → Pages → Branch: `main` / root)를 켜면 휴대폰에서 링크로 바로 플레이할 수 있습니다.

| 동작 | 모바일 | 키보드 |

| 이동 | 화면 아무 곳이나 끌기(손가락·마우스가 움직인 만큼 그대로) | 방향키 / WASD |
| 공격 | 자동 | 자동 |
| 수호령 스킬 | 護 버튼 길게 누르기(수호령이 있을 때) | C 길게 누르기 |

| 전체화면 | ⛶ 버튼 | F |
| 메뉴 결정 · 다음 | 버튼 누르기 | Enter / Space / Z |

| 메뉴 취소 · 건너뛰기 | 버튼 누르기 | Esc |

## 시작 흐름

게임 시작 → 이야기 컷신(5장면, 건너뛸 수 있음) → 수호자 선택 → 복습 범위 → 출격

## 복습 방식

수호자를 고른 뒤 **복습 범위**에서 학년(5학년 · 6학년 · 5·6학년)과 과목(수학 · 국어 · 사회 · 과학 · 영어)을 고릅니다. 한 막마다 문제가 8개 나옵니다.

- **복습 문제**(막마다 5번): 웨이브 사이에 게임이 멈추고 4지선다 문제 창이 뜹니다. 보기를 눌러 고른 뒤 **확인**을 누르면 정답·해설이 나오고, **계속**으로 이어 갑니다(키보드: 1~4로 고르고 Enter).
- **보스의 수수께끼**(보스마다 3번): 보스가 나타날 때와 체력이 ⅔·⅓ 남았을 때 같은 문제 창이 뜹니다. 맞히면 보스에게 「정답 일격」이 들어갑니다.
- 맞히면 영력 → 사신오의 → 기력 순으로 보상을 받고, 틀리면 엽전 배율이 초기화됩니다. 틀린 문제는 조금 뒤에 다시 나옵니다.
- 막이 끝날 때와 게임이 끝날 때 과목별로 **맞힌 문제 / 나온 문제**를 보여 줍니다. 마지막 화면에서 **처음으로**를 누르면 틀린 문제를 모두 맞힐 때까지 다시 푼 뒤 타이틀로 돌아갑니다.
- 문제는 **2022 개정 교육과정 5~6학년군 성취기준**에 맞췄습니다. 직접 쓴 문제 348개(국어 63 · 영어 51 · 과학 105 · 사회 110 · 수학 개념 19)에 문제마다 성취기준 코드(예: `6과01-02`)를 달았고, 숫자를 바꿔 가며 계속 새로 만드는 수학 문제 39종(5학년 20 · 6학년 19)이 더 있습니다.
- 학년 구분은 성취기준 영역이 교과서(5-1~6-2)에 실리는 일반적인 순서를 따릅니다. 3~6학년 수학·사회·과학은 검정 교과서라 출판사에 따라 단원 순서가 조금 다를 수 있습니다. 국어·영어는 5~6학년 공통입니다.

## 구성

- **수호자 4명** — 사신(四神)을 하나씩 이어받았습니다. 모두 처음엔 한 줄로 쏘고, 力(영력)을 먹을 때마다 1~4단계로 갈래가 늘어납니다(해담은 물줄기 굵기도 커짐).
  - 연검객 청운(청룡): 초승달 검기
  - 방울무녀 연화(주작): 부채꼴 부적
  - 매사냥꾼 솔비(백호): 관통 화살
  - 거북선 포수 해담(현무): 물결치는 쌍수탄
- **수호령**: 護 아이템을 먹으면 최대 둘까지 수호자 위아래에 붙어 함께 쏩니다. 護 버튼(C)을 0.5초 누르면 2초 동안 수호령이 둘레를 돌며 적탄을 막고 추적탄을 쏩니다. 쓴 뒤 8초 쉽니다. 피격 범위는 수호자 가운데의 작은 구슬로, 적탄이나 적이 가까이 올 때만 나타납니다.
- **격추와 재출격**: 맞으면 목숨(붉은 옥 하트) 하나를 잃고 화면의 적탄이 모두 사라집니다. 수호자는 왼쪽에서 다시 날아 들어오며 약 2초 동안 무적이고, 오의는 3개, 영력은 1단계로 돌아갑니다. 격추되면 20초 뒤 力 아이템을 가진 약한 날개 상자가 하나 나오고, 보스전에서 격추되면 20초 간격으로 두 번 나옵니다.
- **力(영력) 아이템**은 막마다 5개로 정해져 있습니다. 웨이브 구간에 고르게 날개 상자로 나오며, 다른 적이나 보급 상자는 力을 떨어뜨리지 않습니다(격추 보상은 따로).
- 점수·엽전 배율·복습 정답은 왼쪽 아래 작은 띠에 보이고, 수호자가 그 위로 지나가면 흐려집니다.
- **사신오의(四神奧義)**: 고른 수호자의 신수(청룡·주작·백호·현무 중 하나)가 화면을 휩쓸며 적탄을 엽전으로 바꿉니다.
- **5막**
  - 월하죽림: 보스 흑각귀 철갑거
  - 적염제련소: 보스 백족철왕
  - 노을운해: 보스 묵린 흑룡함
  - 북해빙궁: 보스 설한 구미호 (꼬리 셋을 먼저 부숨, 새 적 얼음 정령)
  - 흑월천궁: 보스 흑철요왕 (쇠주먹 둘이 날아와 내리침, 새 적 철갑 도깨비)
- 엽전 콤보 배율, 부위 파괴 보스, 사신오의 컷인, 아이템(力 영력 · 奧 오의 · 護 수호령 · 命 기력)
- 난이도 쉬움 / 보통 / 어려움 (보통·어려움은 막이 넘어갈수록 적이 더 단단하고 빠르게 쏨), 이어하기, 최고 점수 저장

## 수정하고 빌드하기

`index.html`은 그림을 모두 품은 단일 파일(오프라인 실행용)이라 직접 고치지 않습니다.

- 코드: `src/index.template.html`
- 문제: `src/questions.js` (한 줄에 한 문제: 과목, 학년, 문제, 정답, 오답 3개, 해설, 성취기준)
- 그림: `art/*.webp` (파일 이름이 곧 그림 키) — 수호자마다 다른 수호령 인장 `seal0`~`seal3`(청룡·주작·백호·현무), 피격 구슬 `core`, 4·5막 배경(`stage3`·`stage4`)과 새 적·보스(`ice`·`oni`·`fox`·`tail`·`king`·`fist`)는 로컬 FLUX.2 Klein 4B로 그렸습니다.
- 움직임: 코드의 `RIG`가 그림마다 움직일 부위(날개·천·술·몸통)를 0~1 좌표로 정합니다. 게임이 열린 뒤 이 정보로 6장씩 만들어 씁니다.
- 소리: `audio/*.mp3` — `bgm_title`·`bgm_stage`·`bgm_boss`는 반복 재생 배경음(앞 0.5초 + 고리 + 뒤 1초로 저장, 고리 길이는 코드의 `MUS`), 나머지는 효과음(크기는 `VOL`). 수호자마다 발사음이 다릅니다(`shot0`~`shot3`).
- 글꼴: `fonts/*.woff` — 제목 송명(Song Myung), 본문 고운바탕(Gowun Batang), 한자 Noto Serif KR. 모두 SIL OFL 1.1이며 게임에 쓰는 글자만 담았습니다(`fonts/LICENSE.txt`). 문구나 문제를 바꿔 새 글자가 생기면 `node tools/subset-fonts.js`로 다시 만듭니다(fonttools 필요, 빌드가 알려 줌).
- 빌드: `node tools/build.js` → `index.html` 생성
- 오프라인 압축본: 빌드한 `index.html`을 `Sasin-Flight.html`로 이름을 바꿔 `Sasin-Flight.zip`에 다시 묶습니다.
