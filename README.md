# 사신비행 四神飛行

달을 삼키려는 흑철 요괴군에 맞서는 모바일 횡스크롤 슈팅 게임입니다.
90년대 오락실 슈팅(텐가이)을 참고했고, 조선 판타지에 증기기관 분위기를 섞었습니다.
`index.html` 파일 하나로 돌아가며, 그림은 모두 코드로 그린 도트 그래픽이고 소리는 Web Audio로 직접 만듭니다.

## 실행

- `index.html`을 브라우저에서 열면 바로 실행됩니다.
- GitHub Pages(Settings → Pages → Branch: `main` / root)를 켜면 휴대폰에서 링크로 바로 플레이할 수 있습니다.

## 조작

| 동작 | 모바일 | 키보드 |
|---|---|---|
| 이동 | 화면 아무 곳이나 끌기 | 방향키 / WASD |
| 공격 | 자동 | 자동 |
| 모아쏘기 | 集 버튼 길게 눌렀다 떼기 | C 길게 눌렀다 떼기 |
| 필살기 | 必 버튼 | X |
| 일시정지 | II 버튼 | Esc / P |

## 구성

- **수호자 3명**
  - 연검객 청운: 초승달 검기, 필살 「청룡뇌격」
  - 방울무녀 연화: 추적 부적, 필살 「주작염무」
  - 매사냥꾼 솔비: 관통 화살, 필살 「백호천궁」
- **3막**
  - 월하죽림: 보스 흑각귀 철갑거
  - 적염제련소: 보스 백족철왕
  - 노을운해: 보스 묵린 흑룡함
- 엽전 콤보 배율, 부위 파괴 보스, 필살기 컷인, 아이템(力 영력 · 必 필살 · 護 수호령 · 命 기력)
- 난이도 쉬움 / 보통 / 어려움, 이어하기, 최고 점수 저장
